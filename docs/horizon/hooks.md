Generated by `scripts/horizon-extract-mod-api.py` from horizon `7ef3fdd9e` (`NATIVE_HOOKS_API = 415`): `OUT_DIR/mod_api_generated.rs` (build script of `horizon-client`, generator `crates/horizon-mod-api-gen`) and `native-hooks.json`. Do not edit by hand: rerun the script.

The trait has 534 methods (+ `render`), catalog sides: both 15, client 78, server 340, unlisted 1, unspecified 100. This page lists the 455 that are not client-only: side `server`/`both` from the catalog, or from a pending fragment (`tools/native-hook-fragments/*.json`: merged on main, API number assigned at the next stamp; many hooks Rustic needs are there, e.g. `block_place`, `player_move`, `player_pre_login`), plus `unspecified` (listed without a side) and `unlisted` (in neither). Check an `unspecified`/`unlisted` hook's call site before relying on it server-side; 131 of them are cancellable (they return `Flow`; `Flow::Cancel` sets the flag named in *out* and skips later mods).

**45 of them get no `host`** (only the event): inside them a mod cannot call `Host` helpers and must defer work (e.g. to the next `server_tick`). They are marked *no host* below.

Signatures are reproduced exactly (whitespace normalised). Event structs are `#[non_exhaustive]`.
